The purple-goes-green bug

Not a colour-space quirk — the pages are see-through. Both views fade their theme gradient to .clear, which is fully transparent, and nothing opaque sits underneath. So the bottom-right of the window is literally showing your desktop. On a green-yellow wallpaper, purple reads green. Drag the app over a red wallpaper and it would read red.
Source: ContentView.swift:1248 (Credits) and 1380 (Version History) — same pattern at 351, 750, 803.

The fix 
// ContentView.swift — Credits (1246) and Version History (1378)
.background(
    LinearGradient(
        colors: [activeTheme.color.opacity(0.10),
                 activeTheme.color.opacity(0)],   // was .clear
        startPoint: .topLeading,
        endPoint: .bottomTrailing
    )
)
.background(Color(nsColor: .windowBackgroundColor))   // new: opaque floor

Two changes. The opaque floor is the one that stops the wallpaper. Fading to activeTheme.color.opacity(0) instead of .clear keeps the midtones on-hue rather than drifting toward transparent black — worth doing at the same time, and worth applying to the other three gradients too.

What changed and why

  • Accent stopped doing everything. Today every release bullet is activeTheme.color.opacity(0.9) (ContentView.swift:1370) — a full page of purple body text. In both redesigns the accent marks structure only; body copy is normal label colour.
  • Credits stopped repeating itself. GitHub and LinkedIn currently appear twice: as rows (1209-1221) and again as Quick Links capsules (1229-1241). The capsules also render system blue, not the theme, because Link keeps its own tint. Both concepts drop them and use the space for app facts.
  • The empty two-thirds got a job. Credits ends a third of the way down the window. Version, build, platform, storage and licence now fill it — real data, pulled from the bundle rather than hardcoded.
  • Icons are approximations. SF Symbols aren't available in a browser; these are hand-drawn SVG stand-ins. Fonts are -apple-system, so type renders in the same SF Pro the app ships.
