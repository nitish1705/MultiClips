Fidelity notes

  • Icons are approximations. SF Symbols aren't available in a browser — these are hand-drawn SVG stand-ins. The Swift build uses the real symbol names from clipIconName(for:) at ContentView.swift:1405.
  • Materials are approximations. CSS backdrop-filter stands in for SwiftUI .regularMaterial. Real vibrancy samples the live desktop and will read slightly differently.
  • Type is honest. Panels use -apple-system, so on this Mac they render in the same SF Pro the app ships. Only the surrounding gallery chrome uses a different face.
  • Feature set is frozen. Every concept shows exactly what the menu bar does today — type icon, one-line preview, note-or-timestamp, star, ellipsis sheet, three footer actions. No search, no keyboard nav, no thumbnails.
