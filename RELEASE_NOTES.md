# Release Notes

## v1.2.1 - 26 Mar 2026

### Added

- Per-clip three-dots actions in the menu icon bar.
- Clip actions dialog with Star toggle and Add Text (Note) input.

### Changed

- Removed top add-note text field from the menu icon header.
- Clicking a clip row in icon bar now opens the actions dialog.

## v1.2.0 - 26 Mar 2026

### Added

- Clip search with live filtering.
- Tiny note field for each clip.
- Quick add text option in the top bar.

### Changed

- App now opens directly to All Clips by default.

## v1.1.0 - 19 Mar 2026

### Added

- Theme customization with selectable primary colors.
- Developer/Credits page with external profile links.
- Version History page inside the app.
- Relative copy-time labels for recent clipboard entries.

### Improved

- Context-aware icon selection for clipboard content and file previews.
- Menu bar list readability by removing redundant row decorations.
- Main window open action from menu bar with explicit app activation and notification fallback.

### Changed

- Removed menu bar header clipboard count to reduce visual noise.

## v1.0.0 - Initial Release

### Added

- Clipboard monitoring for text, links, images, files, documents, and media.
- Duplicate detection with recency bumping.
- SwiftData local storage.
- Menu bar quick-copy access.
- Launch at Login setting.
